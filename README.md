# UCS553

Java assignments for UCS553.

| Folder | Contents |
|---|---|
| [Assignment1](Assignment1) | Assignment document (`.docx`) |
| [Assignment2](Assignment2) | Two packaged Java projects: `food` (Regular/Premium orders with discounts) and `library` (books and digital resources) |
| [Assignment3](Assignment3) | Exception handling: 7 problems with custom exceptions (see its [readme](Assignment3/readme.md)) |
| [Assignment4](Assignment4) | `CourseRegistrationPortal` and `MediaPlayerQueue` |
| [Assignment5](Assignment5) | `Q1ArraySum`, `Q2OptionalEmail`, `Q3StudentResult`, `Q4EventManager`, `Q5GenericUtility` |

## Running

Assignment 2 uses packages, so run it from the project folder, for example:

```
cd Assignment2
java food.main.Main
java library.main.Main
```

The other assignments are run from inside their folder, for example `java Q1ArraySum`.
